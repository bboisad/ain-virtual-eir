# 记忆机制与云端存储：Cedar 案例会议演示

目标是在 5–7 分钟内，用已经完成的虚构 Cedar 案例展示：真实 AI 能接续已保存的团队计划，记忆有来源，独立会话读取同一项目，文件可以保存、阅读和完整下载。这是原型可行性演示。

## 演示前准备

- 提前打开 [演示网站](https://ain-virtual-eir-demo.onrender.com) 预热；Render Free 可能休眠。准备普通窗口A和无痕窗口B，分别用共享演示密码进入，选择 Alice、Bob，打开 Campus Loop。
- 当前使用个人 GitHub 仓库、Supabase Free 和 Render Free；真实 OpenAI 模型为 `gpt-5.6-luna`，老师提供的密钥只放在服务端私密配置中。不要在投屏、聊天或交付包中展示密钥。
- 使用已有 Cedar 聊天和附件，避免为演示反复写入同一计划。可复用附件见 [Cedar_Pilot_Plan.txt](demo/Cedar_Pilot_Plan.txt)。
- 记录实际部署版本和验收证据，参照 [部署与恢复说明](CLOUD_DEPLOYMENT.md)。来源文本中 `$36`、`$3` 的显示修复已在本地完成并通过针对性测试，仍需部署和线上复核；不要提前计为线上通过。

## 备用检查（不计入已通过项）

- **未知事实反问，可选，尚未实测：** 发送下面的问题，预期应说明记录缺失，不编造实际付款人数、拒绝原因或转化率：

  ```text
  How many students actually paid in the Cedar pilot, what reasons did the others give for declining, and what was our conversion rate? If we have not recorded results, say so instead of estimating.
  ```

- **并发保护，可选：** 如需展示，提前按 `python scripts/cloud_check.py --write-test` 排练，只展示实际取得的输出。旧版本保存应被拒绝，先成功的结果应保留；冲突要求重新读取，不会自动合并。浏览器刷新可能取得最新版本，不适合临场强行制造冲突。不要关闭版本检查。
- **恢复，可选：** 按 [部署与恢复说明](CLOUD_DEPLOYMENT.md) 先预览历史版本，真实恢复另行安排维护时段。版本快照不能替代数据库及文件的备份。
- 本次交付目标为2026年11月20日；计划日期和交付日期均不是自动执行任务的预约。没有实际操作和证据的检查继续保留为待验收。
